# brain テンプレート — 個人用の永続コンテキスト置き場

## これは何か

**Claude に「自分の文脈」を持たせるための Markdown リポジトリ。**

Claude は毎回まっさらな状態で始まる。同じ前提を毎回説明し直すのをやめるために、
判断基準・プロジェクトの経緯・決定ログを1つのディレクトリに貯め、
そこを作業ディレクトリとして Claude Code を起動する。

肝は**中身ではなく構造**。以下の3点で回っている。

1. **`CLAUDE.md` がルーター** — 全部を毎回読ませない。「何がどこにあるか」だけ書いて詳細に送る
2. **`CONVENTIONS.md` が書き込み規約** — AI に書かせるので、権限レベルと振り分け先を明文化する
3. **各ディレクトリの `README.md` が索引** — 索引に無いファイルは次のセッションで発見されない

## 作り方

```bash
mkdir brain && cd brain
git init
mkdir -p judgment/sources projects log life
cp <このテンプレート>/CLAUDE.md   ./CLAUDE.md
cp <このテンプレート>/CONVENTIONS.md ./CONVENTIONS.md
touch inbox.md SYSTEM.md
for d in judgment projects log; do echo "# $d — 索引" > $d/README.md; done
```

`CLAUDE.md` の `<>` を自分の内容に置き換える。**最初は中身が薄くていい。**
判断基準は書き下ろすものではなく、会話の中で出てきたものを溦めるもの。

あとは `cd brain && claude` で起動する。プロジェクト直下の `CLAUDE.md` は自動で読まれる。

### スキルを置く

このリポジトリの `skills/` を brain の中に置き、`.claude/skills` からシンボリックリンクを張ると、
**スキルの正本が brain 側（＝同期される場所）に一本化される。**

```bash
cd brain
cp -r <このリポジトリ>/skills ./skills
mkdir -p .claude && ln -s ../skills .claude/skills
```

複数マシンで使うなら、この形にしておくと `~/.claude/skills/` を各マシンで同期する必要がなくなる。

### 同期する

Dropbox / Google Drive / Synology Drive 等の同期フォルダに置くと、複数マシンとスマホから同じ
brain を触れる。ただし **git と併用するときは注意**:

- **同期クライアントは `.git/` を壊すことがある。** 除外設定できるなら除外する
- 同期の衝突ファイル（`〜のコンフリクトコピー.md` 等）が湧いたら、放置せず即マージする
- **git は同期の代わりではなく、同期が壊したときの復旧手段として持つ**。
  15分間隔などで自動コミットしておくと、上書き事故から戻せる

## 運用のコツ（実際に踏んだ罠から）

- **判断基準（`judgment/`）は AI に勝手に書かせない。** 「本人がそう考えている」と AI が要約した
  ものが定着すると、以後その AI は存在しない判断基準に従って助言してくる。確認を取ってから書く
- **相対日付を書かせない。** 「先週」は3ヶ月後に読むと意味を失う
- **出典と日付を必ず残す。** 推測と確認済み事実が混ざった瞬間に、蓄積の価値が消える
- **索引の更新が最も忘れられる工程。** セッション終いの儀式（`skills/shimai`）に組み込む
- **一時ファイルを brain に置かない。** 由来不明のゴミが溦まると、次のAIが削除判断できない

## ディレクトリの意味

| ディレクトリ | 置くもの |
|---|---|
| `judgment/` | 判断基準・価値観・癖・文体。**このリポジトリで一番価値が出る場所** |
| `projects/` | 各プロジェクトの事実・構成・経緯 |
| `log/` | 日付つきの決定・学び・インシデント |
| `life/` | デバイス・環境・サブスクなど生活インフラ |
| `inbox.md` | スマホからの一時滞留メモ。棚卸し前提 |
| `SYSTEM.md` | インフラ・ストレージ・アカウント構成 |

`judgment/` が育つまでに数ヶ月かかる。逆に言えば、**そこが育つと替えが効かなくなる。**
